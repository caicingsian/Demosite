THE APPROACH

讓每一步，都朝完成前進。

先從單一 Coding Agent 開始，把規劃、實作、驗證與修復串成循環。你掌握方向，Agent 推進已授權的工作。

01 / DEFINE

說清楚成果

描述使用者、核心流程、限制與完成條件。

02 / BUILD

拆解並實作

建立環境、排序任務，逐步完成可用功能。

03 / VERIFY

測試並修復

執行測試與瀏覽器驗證，失敗時分析原因再修正。

04 / DELIVER

交付並接續

留下原始碼、啟動方式、驗收結果及未解事項。

BUILT FOR CONTINUITY

自主完成，需要能接續的工作基礎。

01 — MEMORY

記得為什麼這樣做

保存產品目標、範圍與決策理由，讓中斷後的工作有據可循。

02 — EVIDENCE

留下完成的證據

任務完成需附驗收紀錄；再由測試與實際操作確認結果。

03 — CONTROL

保留關鍵決策

遇到付費、正式環境變更或重大方向調整時，交回使用者決定。

QUESTIONS & ANSWERS

關於這個實驗

現在已經可以全天候自動開發嗎？

目前工作區已建立，可由對話中的 Agent 執行開發與驗證。獨立背景執行尚未接通，也未驗證離開對話後會繼續運作。

一定需要很多個 Agent 嗎？

第一階段先由單一 Agent 承擔規劃、開發與 QA 職責，驗證完整流程後，再評估是否需要多 Agent 分工。

工作區裝在我的電腦上嗎？

目前環境位於雲端工作區，尚未安裝到使用者電腦。後續需要透過可重現的啟動流程搬移與驗證。

長期想做到什麼？

讓使用者以產品目標管理工作：給方向、看成果、做關鍵決策，由 AI 負責把方向轉為持續改善的產品。
